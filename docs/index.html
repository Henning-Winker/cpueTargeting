cpueTargeting

Simulators for CPUE targeting and standardization

Description of the simulation models

The spatial multispecies simulator (simulate_bathymetric(), after Thorson et al. 2017 and Ono et al. 2015), its extension to a longline tuna fishery with vertical targeting (simulate_tuna()), and the standardisation models (Cluster, DPC, HBF).

Package source on GitHub

Code, README and the vignette Targeting in a longline tuna fishery.
